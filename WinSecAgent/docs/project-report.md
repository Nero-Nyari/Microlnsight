# WinSecAgent 当前项目说明

更新日期：2026-10-03。本说明替代旧版项目总结，描述当前可验证的范围。

## 要解决的问题

Windows 事件日志包含大量正常活动与上下文不完整的记录。WinSecAgent 帮助用户定位值得核查的线索，回看依据，并明确下一步需要补充什么信息。

## 当前实现

React 工作台通过 FastAPI 访问 SQLite 中的导入日志和分析记录。支持 Windows 通道读取与手动粘贴，本地规则按主机、账户、来源 IP、时间关联登录失败和成功，另包含服务路径核查规则。模型分析为可选的单条分析流程。

日志先进入待分析列表。异常线索需要可定位的原文或独立记录支持；正常或证据不足的结果留在日志列表。页面和 Markdown 报告复用同一研判，保存证据快照。没有外部查询时，不生成虚构的资产、威胁情报或漏洞结果。

## 本轮演示交付

- 统一的环境检查、启动与测试入口，显示实际使用的 Python。
- 正常运维、单次失败、连续失败后成功三个可操作场景。
- 第三个场景含 6 条独立合成记录，支持关联、去重、证据回看及报告下载。
- 演示讲解及明确的预期结果，见 [演示指南](demo-walkthrough.md)。

## 尚未证明的能力

用户已手动验证本机五个日志通道的读取，以及网络连接、服务和计划任务列表展示。这证明当前环境中的采集流程可用；真实异常日志的完整分析闭环仍未完成验证。

已有测试验证固定输入下的规则和流程，不证明真实日志的误报率、漏报率、模型泛化能力或商用适用性。时间关联不能证实攻击因果链；正常结果不能证明整机安全。

历史代码含有处置相关接口，本轮工作没有将其作为演示主线，也没有执行或验收真实系统处置。项目未完成生产安全加固、权限体系和多用户部署验收。
