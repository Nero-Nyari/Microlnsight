# Windows 版本验收记录

日期：2026-09-29。

## 已验证

- 56 项后端自动化测试通过，固定合成样本覆盖正常运维、Codex 操作、登录异常、服务创建、去重、范围隔离及历史结论一致性。
- 前端 TypeScript 检查及 Vite 生产构建通过。
- 在内置浏览器验证粘贴导入、平台校验、日志/告警分流、本地联合分析、时间窗口切换、原文展开、报告生成与下载、筛选和刷新。
- 5 条独立失败登录能够关联后续成功登录与服务创建；重复记录不增加次数；窗口外记录被排除。时间关联不被描述为已证实的入侵链。
- 正常或证据不足的记录不生成入侵描述和可执行处置。本地规则无命中时显示待核实，并列出缺失证据。
- Security 无权限时单独显示错误，其他通道读取成功的记录仍可预览。权限帮助说明后端账户和提升状态。
- 修复本地证据列表无说明的百分比、日志筛选无结果空白、告警筛选未命中误称没有告警三处展示问题。
- 对本地数据库全部表逐行比较，测试前已有记录未被覆盖或删除。

## 复现

在应用目录 `WinSecAgent` 下：

```powershell
cd backend
python -X utf8 -m unittest discover -s tests -v
cd ../frontend
npm ci
npm run build
```

合成样本及说明位于 `backend/tests/fixtures/`。测试使用隔离数据库，不需要模型密钥；不要为测试提交真实采集日志或运行数据库。

## 当前限制

- Security 是否可读取决于后端 Windows 账户权限，应用不会自动提权或修改安全配置。
- 联合分析仅覆盖已导入日志；当前规则不能证明服务创建与某次登录之间的因果关系。
- 自动化测试和浏览器验收不能代表外部模型在所有真实日志上的误报率。
- 真实封禁、隔离和删除没有在这次验收中执行。
- 联合分析报告中少量缺失账户/IP 字段仍显示 `None`，页面已显示中文“未提供”。
- 浏览器窄屏检查包含 DOM 尺寸验证，未覆盖所有设备的逐像素视觉验收。
